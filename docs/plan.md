# 기획 요약 (원본: SW융합프로젝트 조별활동기획서_서촌겨울스탬프투어.pdf)

- 프로젝트명: SEOCHON WINTER JOURNAL — 겨울의 서촌을 기록
- 목적: 귀엽고 감각적인 지도 + 스탬프 투어로 겨울 서촌의 카페·소품샵을 큐레이팅, 방문한 순간을 나만의 저널로 남김
- 컨셉: 동글동글한 로우폴리 3D 캐릭터가 사용자 아바타, 매장은 각각 모양이 다른 3D 건물. 실제 간판 문구·판매 물품 컨셉을 차용해 현장과 화면을 연결
- 타깃: 20대 (귀여운 캐릭터·게임형 콘텐츠에 친숙, SNS 인증·공유, 주말·데이트 골목 산책과 카페 투어)
- 기대 효과: 서촌 소상공인 홍보, 골목 체류 시간 증가, SNS 게시물 공유로 자발적 홍보

## 화면
지도 화면 하나를 중심으로 매장 정보와 스탬프 인증이 그 위에 겹쳐 열림. 모은 스탬프와 기록은 윈터 저널 한 권으로 엮임.

| 화면 | 열리는 시점 | 구성 |
|---|---|---|
| 지도(메인) | 접속 시 | 2D 일러스트 지도, 스탬프 대상 매장만 3D 건물, 골목 시작점의 아바타, 상단 진행도(3/8)와 저널 아이콘 |
| 매장 정보 | 3D 매장 탭 (중앙에서 퍼짐) | 가게 이름, 한 줄 소개, 주소, 운영시간, 스탬프 칸(빈 칸/찍힌 칸) |
| 스탬프 인증 | 스탬프 칸 탭 | 매장별 스탬프 문양, 사진 촬영·업로드, 한 줄 기록, 인증 완료 버튼 |
| 윈터 저널 | 진행도·저널 아이콘 탭 | 표지, 매장별 스탬프 칸 모음, 칸별 방문 날짜·사진·한 줄 기록, 완성 페이지와 공유 이미지 저장 |

윈터 저널
- 칸 배치: 대상 매장 수만큼 격자. 찍힌 칸 = 매장 문양 + 방문 날짜, 빈 칸 = 업종 실루엣(커피잔·선물상자·밥그릇)을 흐릿하게
- 찍힌 칸 → 그날 사진 + 한 줄 기록이 일기장 한 페이지처럼, 나중에 수정 가능
- 빈 칸 → 지도로 돌아가 해당 매장 앞에 선 아바타를 화면 가운데로
- 모든 칸 채우면 완성 페이지, 저널 전체를 이미지 한 장으로 저장해 SNS 공유

## 연출 (매장 탭 → 이동 → 정보 → 인증 → 도장까지 끊김 없이)
| 장면 | 연출 | 길이 |
|---|---|---|
| 첫 진입 | 눈 내리는 골목 입구에서 아바타가 손 흔들고 돌아섬 (뒤통수가 보이는 3인칭으로) | 1초 |
| 매장 탭 | 건물이 통 튀듯 살짝 커졌다 돌아옴 | 0.2초 |
| 아바타 이동 | 골목길 따라 걷고 카메라가 부드럽게 따라감 | 거리에 따라 |
| 정보 화면 | 화면 중앙에서 퍼지고 지도는 살짝 어두워짐 | 0.3초 |
| 스탬프 | 도장이 위에서 내려와 쾅 찍히고 잉크 번짐, 햅틱 | 0.5초 |
| 엽서 부착 | 시트 닫으면 건물 벽에 엽서 스탬프가 붙으며 반짝임 | 0.4초 |
| 저널 열기 | 책이 펼쳐지듯 열리고 새로 찍은 칸이 반짝임, 전부 모으면 완성 페이지에 크리스마스 전구 | 0.6초 |

비주얼 무드: 눈 내리는 서촌을 여행 일기장에 기록하는 분위기
- 겨울: 지붕 위 눈, 은은한 창문 불빛, 화면에 살짝 내리는 눈 (실시간 날씨 반영 고려 중)
- 종이 저널: 종이 질감 배경, 마스킹테이프·폴라로이드 같은 다이어리 꾸미기, 기록 부분은 손글씨 폰트

## 기술 설계
실제 지도 API 대신 직접 그린 2D 지도 위에 3D 모델을 올리는 방식, React + Three.js 모바일 웹.

| 영역 | 기술 | 역할 |
|---|---|---|
| 화면 | React + Vite | 세로 모바일 우선 반응형, 화면 전환·상태 관리 |
| 3D | Three.js (R3F, drei) | 지도 평면·아바타·매장 렌더링, 터치 선택(레이캐스팅) |
| 3D 모델 | Blender → glTF(.glb) | 로우폴리 캐릭터 + 업종별 건물 3종, 간판은 텍스처 교체 |
| 지도 이미지 | AI 생성 + 보정 | 서촌 골목을 단순화한 이미지를 바닥 평면에 |
| 카메라 | 내려다보는 카메라 + MapControls | 핀치 확대·축소, 드래그 이동, 회전 잠금 |
| 애니메이션 | GSAP 또는 react-spring | 아바타 이동, 시트 열기, 스탬프 찍기 |
| 사진 촬영 | `<input type="file" accept="image/*" capture>` | 별도 앱 없이 휴대폰 카메라 |
| 저장 | IndexedDB(MVP) → Firebase(확장) | 스탬프·후기·사진 기기 저장, 기기 간 동기화 필요 시 Firebase |
| 배포 | Vercel 또는 GitHub Pages | HTTPS 주소 (카메라·위치 권한에 필요) |
